III. COURSE DESCRIPTION :

This course introduces students to intermediate programming concepts, with a focus on object-oriented programming (OOP) principles and practices. Students will explore object-oriented design, encapsulation, information hiding, classes, subclasses, inheritance, polymorphism, class hierarchies, collection classes, iteration protocols, and fundamental design patterns. Practical programming exercises will be conducted using Java, allowing students to develop both analytical and problem-solving skills essential for software development.

The course also emphasizes the use of APIs, event handling, and exception management, providing students with the tools to create robust, efficient, and maintainable programs. Programming tasks are designed to challenge students to apply logical thinking, algorithmic skills, and systematic debugging strategies, ensuring readiness for more advanced software engineering courses.

Consistent with Christo-centric Catholic and Marian–Augustinian values, the course integrates ethical and socially responsible programming practices. Students are encouraged to develop discipline, perseverance, humility, and collaborative spirit, fostering not only technical competence but also the formation of values-driven professionals who contribute positively to society.
